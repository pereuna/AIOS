# Projektin taustakeskustelut

Alkuperäiset ChatGPT-jakosivut muunnettiin 10.9.2026 tavalliseksi Markdowniksi.
Mukana ovat vain käyttäjän ja avustajan näkyvät viestit. Sivuston HTML,
JavaScript, järjestelmäviestit, sisäinen päättely ja työkalulokit poistettiin.

- [Kielimallin logiikkaa](conversations/kielimallin-logiikkaa.md): numeerinen
  representaatio, tokenisointi, dataflow ja AI:n työkalut.
- [Dataflow ja tikapuukaaviot](conversations/dataflow-ja-tikapuukaaviot.md):
  rinnakkainen laskenta, opittu säätö ja ohjelmistokerrosten rooli.
- [Neuroverkon biokudostesti](conversations/neuroverkon-biokudostesti.md):
  biologinen hermokudos, I/O ja oppiminen.
- [Neuroverkon digitaalinen lisääntyminen](conversations/neuroverkon-digitaalinen-lisaantyminen.md):
  digitaalinen hermokudos ja tämän SmolLM2-kokeen lähtökohta.

Viidestä HTML-tallenteesta yksi oli `Kielimallin logiikkaa` -keskustelun
lyhyempi, täsmälleen samanlainen alkuosa. Markdownissa säilytetään vain pidempi
versio, joten yhtään ainutkertaista viestiä ei menetetty eikä samoja viestejä
toisteta kahdesti.
